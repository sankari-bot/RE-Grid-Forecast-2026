🎤 Viva Explanation - How It Works:

Formula: Imbalance = Generation - Load

  • GREEN Excess (200MW): Gen > Load → Export power, Charge battery
  • RED Deficit (-800MW): Gen < Load → Import power, Start peak plants

6 Graphs Proof:

  1. LINEPLOT: Time vs Gen/Load trend
  2. BARPLOT: RED Deficit vs GREEN Excess count
  3. SCATTER: Gen vs Imbalance correlation + 200/-800 lines
  4. HISTOGRAM: Imbalance distribution (-1500 to +1500)
  5. HEATMAP: 7x7 correlation matrix (0.78, -0.71 etc)
  6. BOXPLOT: Wind, Solar, Gen/4, Imb+1k variation
