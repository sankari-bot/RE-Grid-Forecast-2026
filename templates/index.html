About The Project

Renewable energy sources are variable due to weather. This causes grid imbalance - generation vs load mismatch leading to blackouts. Our solution combines weather data + smart grid data to predict imbalance using LSTM, Random Forest, XGBoost.

Objectives:
  • Real-time prediction
  • Weather-aware forecasting
  • Grid stability
  • Reduce wastage
Tech Stack:
  • Python, Pandas, Sklearn
  • HTML,CSS,JS,Chart.js
  • Flask Backend
  • LSTM,RF,XGBoost
