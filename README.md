# Renewable Energy Imbalance Forecasting 2026
- Accuracy: 96.4%
- Formula: Imbalance = Generation - Load
- GREEN 200MW = Excess (Export) | RED -800MW = Deficit (Import)
- Tech: Flask + Pickle (model.pkl, scaler.pkl) + Matplotlib 6-in-1 Dashboard
- Run: python renewable.py -> http://localhost:5000/dashboard
